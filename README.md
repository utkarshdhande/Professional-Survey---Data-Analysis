# Professional-Survey-Data-Analysis
Data Analysis for the programmers who are working in data field

This is the real survey which was done with programmers around the world, working in data field. I have performed data analysis in Power BI, transformed data, utilized DAX queries to create a dashboard with good visualizations.

I have answered various questions such as:

1. Total number of survey takers?
2. What is the average age of survey takers?
3. Average salary by job title.
4. What programming language people are using most.
5. Which Country the programmer's belong to?
6. How happy are programmer's in terms of work life balance?
7. How happy are the programmer's with their salary?
8. How difficult is to break into data field?
